# Current handoff

- Stage: app-like public-catalog TUI with portable playback draft; package not published.
- Branch: `codex/streamer-tui-first-draft`.
- Playback: miniaudio streams direct MP3/WAV/FLAC/Vorbis audio with TUI pause/stop; Linux aarch64 uses system-browser audio. Windows/Linux ASCII video uses OpenCV grayscale frames (silent). macOS standard install opens video in browser; macOS 13+ can add the `ascii-video` extra. ASCII mode automatically falls back to browser if cv2 is absent.
- Dependency/license: OpenCV headless 4.12 is pinned on Windows/Linux and optional on macOS 13+, installed as its own LGPL FFmpeg wheel (not embedded). Notices: https://github.com/opencv/opencv-python/blob/4.x/LICENSE-3RD-PARTY.txt and https://github.com/opencv/opencv-python/blob/4.x/README.md. PyAV/imageio-ffmpeg were rejected because checked wheels enabled GPL components.
- Intended install targets: Python 3.11–3.14; macOS Intel/Apple Silicon, Windows x64, Linux x86_64/aarch64. OpenCV 4.12 wheels cover Windows x64/Linux x86_64/aarch64 and macOS 13+; Big Sur and macOS 12 or older use browser video. Miniaudio's missing Linux aarch64 wheel is handled by browser fallback. Device audio and live HTTPS video decode have not been manually verified across hosts.
- Verification: 12 offline tests pass in the temporary Python 3.14 environment with miniaudio; synthetic WAV decoding, fake audio device controls, and synthetic ASCII frame output pass. In the base environment, 11 tests pass and the real miniaudio WAV decode test skips because miniaudio is absent. Compileall and `git diff --check` pass. Built a wheel and installed it into a clean target using `--no-deps`; version/help/doctor smoke passed. Full dependency resolution/install, OpenCV wheel install, live HTTPS decode, and physical audio output are unverified because network access is restricted and OpenCV isn't present.
- Parity gaps: video ASCII is silent; no seeking, auto radio track rollover, synchronized AHOY TV schedule, richer detail routes, accounts, cross-device sync, payments, downloads, admin, saved playlists, or playback after app exit.
- Follow-up: manually verify real audio and a short HTTPS video on macOS/Windows/Linux; check resize/color/terminal behavior and wheel notices in clean installs. Then address richer details/TV schedule and release packaging separately.
